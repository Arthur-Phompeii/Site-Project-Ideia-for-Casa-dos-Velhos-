Data Structure

Data Types

Em python, existem alguns tipos de datas que servem para propósitos específicos:

Listas [..., ..., ...,]

Lista é uma coleção mutável e ordenada de elementos. Elas são delimitadas por colchetes e seus elementos são separados por vírgulas. Em Python é permitdo que diferentes tipos de dados possam ser armazenados simultaneamente em uma mesma lista.

Os elementos de uma lista são definidos por um índice, em python, inicia-se por 0. Também há a indexação negativa, onde -1 signica o último elemento, -2 o penúltimo, e assim por diante.

Para a lista (tipo de data), temos alguns métodos, sendo eles:

  • list.append(value, /..)

    Adiciona um item ao fim da lista.

  • list.extend(iterable, /..)

    Extende a lista, adicionando-a todos os itens de uma determinada variável.

  • list.insert(index, value, /..)

    Adiciona um item em uma determinada posição da lista.

  • list.remove(value, /..)

    Remove o primeiro item da lista cujo valor seja igual à value. Devolve um 'ValueError' se não houver tal item na lista.

  • list.pop(index=-1, /..)

    Remove o item em dada posição da lista, e retorna-o. Se um index não for especificado, .pop() remove e retorna o último item da lista. Devolve um 'IndexError' se a lista está vazia ou o index está foram do alcançe da lista.

  • list.clear()

    Remove todos os itens da lista.

  • list.index(value[, start[, stop]])

    Retorna um index de base 0 da primeira ocorrência do valor na lista. Retorna um 'ValueError' se tal item não existe.

  • list.count(value, /..)

    Retorna o número de vezes que determinado valor aparece na lista.

  • list.sort(*, key=None, reverse=False)

    Organiza os itens da lista.

  • list.reverse()

    Inverte os elementos da lista.

  • list.copy()

    Retorna uma cópia da lista.

Tuples and Sequences

Embora não seja obrigatório, tuplas são criadas com parênteses, e significam um conjunto imutável de dados

Sets (conjuntos)

É uma coleção sem ordem e que não aceita duplicatas.

Alguns métodos são:

  • remove()

    Gera erro se o valor não for encontrado

  • discard()

    Não gera erro se o valor não for encontrado

Mappings (dicionário)

Dicionários são indexados por chaves(keys), imagine como se fossem rótulos para os valores.

Alguns operadores são:

  • keys()

    Retorna todas as chaves de um dicionário

  • values()

    Retorna todos os valores de um dicionário

  • items()

    Retorna todos os conjuntos chave-valor de um dicionário

  • get()

    Retorna um valor padrão se determinada chave não existir

Built-in Types

Os principais são: numéricos, sequenciais, dicionários, instâncias e exceções.

Tipos Numéricos

  • int

  • float

  • complex

Tipo Booleano

O boolean é um subtipo de int, pois ele só pode assumir dois valores, True ou False.

Tipos sequenciais

São variáveis que podem ser mutáveis ou imutáveis, e são divididos em três principais:

  • list[]

    São sequências mutáveis, e podem ser constrídas de diversas formas:

    • Usando colchetes [] para denotar uma lista vazia, ou com valores separados por vírgulas [..., ..., ...]
    • Ou usando um construtor de tipos: list()

  • Tuples()

    São sequências imutáveis, e podem ser construidos com:

    • Uso de parentêses () para denotar uma tupla vazia, ou com valores separados por vírgulas (..., ..., ...), para se criar uma tupla com um único valor adiciona-se uma virgula após o valor (...,)
    • Ou usando um construtor de tipos: list()

  • Range

    o tipo Range representa uma sequência imutáveis de números, e é comumente utilizada para circular uma número específico de vezes em um laço for.

    range (stop, /..)

    range(start, stop, step=1, /..)

    A vantagem de range é que ele ocupa sempre a mesma (pequena) quantidade de memória, não importando o tamanho do seu alcance, já que ele somente guarda os valores de inicio, fim, e step.

Como uma subdivisão dos tipos sequênciais, temos os tipos textuais e binários:

  • Text Sequence Type

    É um tipo de variável imutável, e é manejado através de strings

  • Binary Sequence Type

    É usado para manipular informação binária através do bytes, bytearray e memoryview

Set (conjuntos) Types{}

Set é um objeto sem ordem, e é uma coleção de diferentes objetos "hashable". Removem duplicatas de uma sequencia e aceitam operações matemáticas como interseção, união e etc. Existem dois tipos:

  • set

    Esse é mutável, e portantanto não hashable, através de métodos como add() ou remove()

  • frozenset

    Esse é imutável e hashable.

Sets podem ser criados de diversas fórmas:

  • Usando elementos separados por vígulas dentro de chaves {}

  • Usando o construtor de tipo set()

Mapping (dicionário) Type{:}

Usado para mapear valores hashable parar objetos arbitrários, atualmente só existe um tipo que é o dict

Ele é criado através de pares de valores separados por vígulas dentro de chaves {key:value, key:value, ...:...}

Ou tilizando o construtor dict()

É como se fosse uma lista, onde cada valor també é atribuido a uma chave, ou seja, um valor arbitrário, como se fosse uma espécie de rótulo para aquele valor, por isso chama-se dicionário
